# MusicHub — Music Practice Hub

A practice log for musicians. Start a session with a timer and metronome, track tempo goals for each piece, and see your weeks laid out as bars on a music staff. Supports English and Vietnamese, light and dark themes, and includes an admin area for the shared song library.

**Stack:** Laravel 13 · Inertia 3 · React 19 · TypeScript · Tailwind CSS 3 · MySQL 8 · Pest 5

## Features

- **Practice mode:** a large timer, a Web Audio metronome with tap tempo, and wake lock to keep the screen on. A session survives a page refresh, and the timer and metronome fill in duration and tempo when you finish.
- **Today:** daily goal ring, streak, "practise next" suggestions, and four weeks drawn on a staff.
- **Pieces:** learning / polishing / mastered, a tempo chart per piece, and session notes. Members can add their own private pieces and suggest them for the shared library.
- **Goals:** a tempo target with a deadline and a pace hint. The goal completes automatically when a session reaches the tempo.
- **History:** a year heatmap, filters, edit, and delete with undo.
- **Insights:** minutes per week by instrument, top pieces, time of day, and busiest days.
- **Onboarding, settings and CSV export**, with per-user timezone and language.
- **Admin:** site overview, library moderation (approve/reject), instruments, and users (roles, suspend).

## Getting started

Requirements: PHP 8.3+, Composer, Node 20+, and Docker (for MySQL).

```bash
cp .env.example .env
composer install
npm install --legacy-peer-deps
php artisan key:generate

docker compose up -d mysql      # MySQL on 127.0.0.1:3307
php artisan migrate --seed

php artisan serve               # http://127.0.0.1:8010
npm run dev                     # Vite on 5180
```

Seeded accounts (password `password`):

| Email | Role |
|---|---|
| `admin@example.com` | Admin |
| `test@example.com` | Member with ~10 weeks of demo practice |
| `linh@example.com` | Member with a library submission waiting for review |

The ports (8010 / 5180 / 3307) are set in `.env` so the app can run alongside other local projects.

## Tests

```bash
php artisan test --compact
npx tsc --noEmit
```

Tests use the MySQL `testing` database, which the Docker container creates. Don't run two test processes at the same time.
